# 文件管理：目录、生命周期、快照

## 推荐目录

```
论文/
  开题报告.docx
  参考论文/            范文 PDF，按来源分子目录（导师推荐、本院同类、外校、行业文献）
  学校规范/            撰写规范、封面格式、参考文献国标
  企业数据/            台账、工艺单、客诉记录、访谈记录等原件，只读不改
  写作过程/
    决定日志.md        ← 活文件，每次开工先读
    00-写作大纲.md  01-论文目录.md  02-数据索取清单.md  03-参考文献待办.md
    主题线对应表.md  方法说明.md
    04-数据解读与正文影响.md  05-格式要求要点.md  参考文献.md  参考文献核对清单.md
    摘要.md  第1章-xxx.md … 第6章-xxx.md  附录A-xxx.md  致谢.md
    图/   脚本/ + 导出的 svg、png
    word/ 生成配置 + 当前版本 docx
    归档/ 快照 zip；一次性/ 子目录放已合并结论的分析报告
    tmp/  临时文件，可整目录删
```

编号只用来给最常用的活文件排序，不编号的也可以是活文件（如主题线对应表、方法说明）。一次性文件不编号，免得后来合并、归档时留下断号。

## 三类文件

| 类别 | 判断标准 | 规则 |
|---|---|---|
| 活文件 | 写作全程持续更新，别人问“现在的口径是什么”要去查它 | 固定文件名，原地更新，不复制加后缀 |
| 一次性文件 | 为回答某个问题做的分析或采集，问题回答完它就完成了使命 | 做完后把结论合并进活文件（决定日志、大纲、数据解读），原件移入 `归档/一次性/`。移动由助手做，不需要删除权限 |
| 临时文件 | 脚本中间输出、试排的 docx、缩略图 | 一律放 `tmp/`，作者定期整目录删 |

助手新建文件前先问自己：这是活文件还是一次性文件？是一次性的，就在文件开头写明“结论已合并到 ×××，本文件可归档”的提示，并在做完时自己移走。

## 快照

回退靠快照，不靠复制加“_xx前”后缀。每轮大改前：

```
python scripts/snapshot.py 写作过程 "标题调整前"
```

生成 `写作过程/归档/20250315_标题调整前.zip`，包含除 `归档/` 和 `tmp/` 以外的全部内容（源稿、图、脚本、配置、当前 docx）。一个时间点一个文件，要回退就解压到临时目录对比或覆盖。

什么时候快照：提交导师前、按导师意见大改前、每轮整体审查前、换标题或改结构前。小改不用。

快照文件也会积累，但一个时间点只有一个文件，按日期排好找，清理时按日期删最早的几个即可。

## 版本号

Word 文件名带版本号（`题目_作者_初稿V0.2.docx`）。什么时候升版本号由作者定，常见做法：提交导师看的升一版，中间修改覆盖当前版。源稿不带版本号，历史靠快照。
