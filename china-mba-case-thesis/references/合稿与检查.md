# 阶段 5 合稿与检查：细则

## 先定规范，写成配置

把学校的《学位论文撰写规范》和导师推荐论文的实际排版整理成一份《格式要求要点》，再填进 `scripts/docx/thesis.config.example.json` 的副本。配置分两部分：

- **学校格式**：页边距、字体字号、标题样式、页眉内容与格式、页码位置与数字格式、目录格式、图表题位置与字体、关键词格式、参考文献格式。规范文件和范文实际做法不一致时，以范文为准并记入决定日志。
- **封面与扉页**：版式和字段（题目、作者、学号、分类号、单位代码、领域、导师、日期、校徽）。需要作者提供的信息（学号、分类号、完成时间）列成清单去问。

生成脚本只有通用逻辑，换学校只换配置。原创性声明、授权声明等页面通过 `extraFrontFiles` 以普通源稿的形式加进去；初稿阶段通常不需要。

## 生成

```
cd scripts/docx
python build_docx.py <配置.json> <输出.docx>
```

只用 Python 标准库，不需要装任何包。

脚本做的事：分节（封面 → 中文摘要 → 英文摘要 → 目录 → 每章一节 → 参考文献），各节单独设页眉页脚；前置部分罗马数字页码，正文从第 1 章起阿拉伯数字从 1 开始；中西文字体同时设置；覆盖 Word 内置 Heading 1–3 样式，编号写在标题文字里；插入目录域并设“打开时更新”；标题、图片段落、表题、表格行设“与下段同页”，表头跨页重复、行不跨页；三线表只有表头加粗，列宽按内容估算。

作者已有能用的生成脚本时可以沿用，只需把写死的路径、封面信息、图注改成从配置读取。

## 检查（每次生成后按顺序做）

1. **文本对比**：`python scripts/check/docx_text_diff.py 上一版.docx 新版.docx`，按句对比正文，确认只有预期的改动。改了一处却多出十处差异，通常是源稿约定没遵守（备注行漏了 `>`、表注没以“资料来源”开头之类）。
2. **版面抽查**：`python scripts/check/render_pdf.py 新版.docx 新版.pdf --thumbs tmp/缩略图`，看封面是否溢出、图表是否被拆页、表格列宽是否合理。缺宋体和 Times New Roman 的机器排出来的页码会和 Word 差一两页，这一步只看版面，页码以 Word 为准。Windows 上要用 LibreOffice 自带的 Python 运行（`"C:\Program Files\LibreOffice\program\python.exe"`）。
3. **Word 收尾**（作者在自己电脑上做）：打开文件 → 若有“受保护的视图”先点“启用编辑” → 提示更新域时点“是”，或右键目录 → 更新域 → 更新整个目录 → 用原文件名保存。跨页表格的“续表”在定稿时手工加。
4. **目录核对**：`python scripts/check/toc_check.py 新版.docx`。查两件事：目录条目文字是否与正文标题一致（改了标题没更新目录时能查出来）；用 Word 保存时留下的分页标记推算每个标题的页码，与目录比对。Word 不在表格内部留分页标记，脚本遇到跨页表格会自动补一页并提示；仍有差异的再去 Word 里核实。
5. **文件一致性**（只在生成环境和作者电脑不是同一台机器时需要）：文件传递后用 md5 核对两边一致；每次用不同的暂存文件名，避免写回旧缓存；文件在 Word 里打开着时无法覆盖，先关掉或另存新版本号。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 目录是空的 | 脚本只写入目录域，内容要 Word 更新后保存才有。在受保护视图下更新过的保存不进去；另存成别的文件名也会以为没生效 |
| 写作备注跑进正文，或图注表注没出来 | 只有 `> 资料来源…`、`> 注…` 会输出，其余 `>` 行是备注。核对源稿约定 |
| “打开时更新域”一直提示 | Word 保存一次后自动消失，正常 |
| 解析 Word 保存过的文件时找不到标题样式 | 中文 Word 会把 `Heading1` 存成 `1`，两种 ID 都要认 |
| 用 sed 改中文把字截断了 | 文本替换改用 Python，每条替换检查只匹配到一处 |
| 封面溢出到第 2 页 | 减少配置里的 `blank` 行 |
| 表格太宽或列宽失衡 | 列宽按文字长度估算，表头特别短或内容特别长时手动在源稿里缩短表头、换行 |
| 图片找不到 | 源稿里 `![图 x.x](路径)` 的路径存在就按路径取；不存在时按“图x.x_”前缀到配置的图片目录找 |
